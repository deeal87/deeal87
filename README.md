# Sunny Stop

A cosy bus-terminal puzzle game for Android and iOS.
200+ levels, rising difficulty, and **no ads between levels** — after every level you win,
you get a kind word instead.

- 📄 **[CONCEPT.md](CONCEPT.md)** — full game concept: gameplay, difficulty model,
  reward system, tech stack, plan and open questions.

**Status:** concept / pre-production. No code yet.
**Planned stack:** Unity 6 LTS + C# (one codebase for Android + iOS).
